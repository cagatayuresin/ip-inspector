About

IP Inspector calculates IPv4 addresses and CIDR blocks in your browser. There is no server, no account, and no tracking. The source is on GitHub, and a live copy is published with GitHub Pages.

Help

  • Enter an address such as 192.168.1.10 or a block such as 10.0.0.0/8, then choose Analyze or press Enter.
  • An address on its own shows that address: scope, class, integer, hexadecimal, reverse DNS, and binary. Add a prefix, such as /24, when you want the subnet.
  • /31 is a point-to-point link: both addresses are usable and there is no broadcast. /32 is a single host.
  • Scope names follow the IPv4 special-purpose ranges: private, shared CGNAT, loopback, link-local, documentation, benchmarking, multicast, and reserved space. A block that crosses those ranges is marked as mixed.
  • Typical gateway is only the usual first usable address. It is not a detected router.
  • Export or copy the whole report, or copy one value from its card.
  • History stays in this browser. Clearing it removes only that list.
